# Casper Academy of Excellence website

Plain PHP pages sharing one header and footer, built into static HTML and hosted free on **Cloudflare Pages**.
The blog (old WordPress posts plus new ones) is part of the same build. No database, no server to maintain.

## Writing a blog post (Pages CMS)

1. Go to **https://app.pagescms.org** and sign in with GitHub (an account with access to `Aakarsh-B/casperacademy.in`).
2. Open **casperacademy.in** → **Blog posts** → **Add an entry** (or click a post to edit it).
3. Fill in the title, URL slug, publish date, author, categories, cover image and the post itself.
   Summary, Google title/description and tags are optional.
4. Click **Save**. The site rebuilds automatically and the post is live at
   `www.casperacademy.in/blog/<slug>/` in about **2 minutes**.

To delete a post, open it and use **Delete**. To add another writer, give them access to this GitHub repo.
Images uploaded in the editor are saved in `blog/images/`.

## How it's built and published

```
content/blog/*.json      blog posts (one file each; edited in Pages CMS, see .pages.yml)
content/blog-*.json      blog categories, tag names, blog home SEO text
blog/wp-content/uploads  images from the old WordPress blog (same addresses as before)
blog/images              images uploaded in Pages CMS
tools/build.php          builds everything into dist/ (site pages + blog + sitemap + feed + redirects)
tools/blog.php           blog templates (same markup as the old WordPress theme)
_redirects, _headers     Cloudflare redirects (old addresses) and headers
tools/wrangler.jsonc     Cloudflare Workers config, copied into dist/ (Cloudflare runs `npx wrangler deploy` there)
.github/workflows/deploy.yml   runs the build on every push to main and publishes dist/
                               to the `cloudflare-pages` branch, which Cloudflare deploys
```

Build locally: `php tools/build.php`, then preview with `npx wrangler pages dev dist`
(or `php -S localhost:8000 router.php` for just the PHP pages).

The contact form posts to [FormSubmit](https://formsubmit.co), which emails info@casperacademy.in
(`contact.php` switches to it in the static build; the checks run in the browser).

## Site pages

```
index.php            homepage
about.php            /about
ielts.php, pte.php, communicative-english.php
                     course pages, all rendered by partials/course.php
gallery.php          /gallery (classroom photos + result posters, photo viewer)
faq.php, essay.php   /faq and /essay (content in data/faq.json, data/essays.json)
contact.php          /contact (enquiry form)
404.php              page-not-found
partials/header.php  <head>, SEO tags, site header (each page sets $page first)
partials/footer.php  site footer, organisation schema, scripts
assets/              css, js, images (assets/css/blog.css is the blog's own styles)
sitemap.xml          generated by the build (pages, blog, categories)
```

## Add a page
Copy `ielts.php`, change the `$page` array (title, description, path, nav) and the content, and push.
`/new-page` is served from `new-page.html` automatically and added to the sitemap.

## Old addresses
`_redirects` permanently redirects every old page: `*.php` to the clean URL, `contact-us` to `/contact`,
`frequently` to `/faq`, `services` to `/about`, the 22 old footer keyword pages to the matching course page,
and old WordPress addresses (`/blog/feed/`, Yoast sitemaps, author pages) to their new equivalents.
Blog posts, categories and tags keep their exact WordPress URLs.

## Accessibility (WCAG 2.2 AA)
Checked on every page at desktop and mobile with axe-core (0 violations), plus manual checks:
keyboard-only navigation with visible focus, skip link, menu opens/closes by keyboard (Esc closes),
focused items never hidden under the sticky header, 200% and 400% zoom without sideways scrolling,
colour contrast of every text/background pair (4.5:1 text, 3:1 controls), reduced-motion respected.
Breakpoints are in `em` so the layout adapts when people enlarge their browser text size.
Header styles: `'header' => 'overlay'` only on pages with a dark photo hero (homepage); every other page
gets the solid white header by default.
